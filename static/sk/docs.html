Požiadajte o kľúč a zaregistrujte doménu webu na stránke API prístupu. Ak už máte aktívny kľúč Addresswise, funguje aj pre Companywise.

Našepkávanie v prehliadači: prehliadač posiela Origin automaticky. Zaregistrujte skutočnú doménu webu pri svojom kľúči. Zahŕňa automaticky aj subdomény. Addresswise · 1 kredit za odpoveď

Našepkávajte adresu od ulice.

Zadávanie adresy začína ulicou. V e-shope alebo CRM použite tento postup:

  1. Navrhnite ulice. Pošlite text a krajinu s prázdnym príznakom street_only .
  2. Doplňte číslo domu. Po výbere ulice hľadajte znova bez street_only a získate úplné adresy.
  3. Vyplňte formulár. Použite objekt address z vybraného výsledku na doplnenie obce a PSČ. Overenie je samostatná voliteľná požiadavka.
GET/search
Požiadavka · Našepkávanie
curl 'https://addresswise.eu/search?q=Hlavna&country=SK&limit=5&api_key=YOUR_API_KEY&street_only' \
  -H 'Origin: https://YOUR_ALLOWED_DOMAIN'

1 kredit za úspešnú odpoveď · povoľte doménu svojho webu

Ukážka JSON odpovede (skrátená)
{
  "results": [
    {
      "formatted": "Hlavná, Košice, SK",
      "address": {
        "thoroughfare": "Hlavná",
        "locality": "Košice",
        "country_code": "SK"
      }
    }
  ]
}
Dôležité: použite &street_only, nie &street_only=true. Pri hľadaní čísla domu príznak vynechajte. Použite oneskorenie pri písaní (ukážka na webe používa 300 ms); každá dokončená požiadavka stojí 1 kredit.
Parameter dopytuPoužitie
qText ulice, potom ulica a číslo domu.
countryDvojpísmenový kód, napríklad CZ alebo SK. Dostupné krajiny nájdete v živej ukážke .
limitMaximálny počet návrhov, napríklad 5.
api_keyVáš aktívny API kľúč s povolenou doménou.
street_onlyPrázdny príznak pre ulice; pre úplné adresy ho vynechajte.

Použite štruktúrovaný výsledok

Čítajte results[]. Každý výsledok obsahuje formatted, score, country_code a address. Objekt adresy obsahuje thoroughfare (ulica), premise (číslo domu), locality (obec), postal_code a full_addressa voliteľné polia správnych celkov a častí adresy. Voliteľné hodnoty môžu byť null.

Existujúce integrácie API

/suggest zostáva alternatívou vyhľadávania. Existujúce parametre postal_only a postal_code zostávajú zachované kvôli kompatibilite. Webové rozhranie vyhľadáva iba od ulice.

Addresswise · 3 kredity za odpoveď

Overte úplnú adresu.

Pošlite štruktúrovanú adresu po výbere alebo overte adresu, ktorú už máte. Táto požiadavka je nezávislá od našepkávania.

POST/validate?api_key=YOUR_API_KEY
Požiadavka · Overenie adresy
curl 'https://addresswise.eu/validate?api_key=YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"street":"Hlavná","house_number":"1","postal_code":"04001","city":"Košice","country":"SK"}'

3 kredity za úspešnú odpoveď · počíta sa aj adresa vyžadujúca kontrolu

Ukážka JSON odpovede (skrátená)
{
  "valid": true,
  "confidence_ratio": 1.0,
  "corrected_address": {
    "thoroughfare": "Hlavná",
    "premise": "1",
    "locality": "Košice",
    "postal_code": "04001",
    "country_code": "SK"
  }
}

Telo JSON používa country, street, house_number, postal_code a city. Hlavička Origin sa nevyžaduje. Odpovede obsahujú valid, confidence_ratio, corrected_address a suggestions.

Spracujte výsledok vyžadujúci kontrolu. HTTP 200 s valid=false je dokončené overenie, nie chyba API. Ponúknite návrhy alebo nechajte používateľa skontrolovať údaje. Stojí 3 kredity.

Companywise · 5 kreditov za odpoveď

Vyhľadajte firmu podľa IČO.

Použite CZ alebo SK a osemmiestne IČO ako text, vrátane počiatočných núl. Kontrola DPH je súčasťou rovnakej požiadavky.

GET/companywise/api/v1/subjects/{country}/{ico}
Požiadavka · Firemné údaje
curl 'https://addresswise.eu/companywise/api/v1/subjects/CZ/27082440?minimal=true' \
  -H 'Authorization: Bearer YOUR_API_KEY'

5 kreditov za úspešnú odpoveď · vrátane kontroly DPH

Ukážka JSON odpovede (skrátená)
{
  "country": "CZ",
  "ico": "27082440",
  "records": [
    {
      "name": "Alza.cz a.s.",
      "established_on": "2003-08-26",
      "addresses": [
        {
          "city": "Praha"
        }
      ]
    }
  ]
}
RežimČo dostanete
minimal=trueStručné records[] s názvom, established_on, nace_codes a štruktúrovanými adresami, doplnené súhrnom DPH.
minimal=false (predvolený)Podrobné registry.records[], údaje o registroch, pôvodné zdrojové dáta a podklady DPH.
all_registers=trueZahrnie všetky dostupné registre namiesto predvoleného výberu obchodných a živnostenských registrov. Funguje s oboma režimami odpovede.

Užitočné zjednotené polia

established_on
Dátum vzniku firmy vo formáte YYYY-MM-DD alebo null, ak nie je dostupný.
nace_codes
Kódy kategórií ako reťazce, bez názvov. CZ používa aktuálne CZ-NACE z ARES; SK poskytuje hlavnú činnosť, ak je dostupná.
addresses[].city a municipality
CZ city používa samostatný názov obce zo zdroja. SK city vzniká skrátením názvov mestských častí Bratislavy a Košíc. Pôvodné municipality sa zachováva.
vat a aktuálnosť
Sledujte neznáme hodnoty a príznaky zastarania. Neznámy stav DPH neznamená, že firma nie je platiteľom.

Stručná aj úplná odpoveď stojí 5 kreditov. Počíta sa aj dokončené hľadanie bez výsledku. Zdroje, polia s hodnotou null, chyby a vyplnené ukážky sú v úplnej schéme.

Kredity & chosen-package limits

Oba produkty zdieľajú mesačný kreditový limit na jednom API kľúči. Našepkávanie (/search alebo /suggest) stojí 1 kredit za úspešnú požiadavku; POST /validate stojí 3; vyhľadanie firmy v Companywise stojí 5, rovnako pre stručné aj úplné odpovede a všetky voľby registrov.

Úspešná HTTP odpoveď sa počíta aj vtedy, keď našepkávač nenájde zhodu, overenie vráti valid=falsealebo vyhľadanie firmy nenájde záznam vo vybraných registroch. Opakované a cachované úspešné dopyty sa počítajú znova. Chyby vstupu, prihlásenia, servera a prekročenia limitu nestoja nič. Požiadavka sa môže započítať aj po prerušení v prehliadači, ak ju server už dokončil.

Mesačné balíky sú Free (0 €, do 1 000 kreditov), Starter (5 €, do 100 000), Growth (10 €, do 1 000 000) a Unlimited (25 €, bez mesačného limitu kreditov). Ide o zvolené balíky, nie automatické zvýšenie podľa spotreby. Limity sú celkové, nie navyše k Free; nevyužité kredity sa neprenášajú. Limit sa obnovuje o 00:00 UTC prvého dňa kalendárneho mesiaca.

Pred spracovaním sa kredity atomicky rezervujú, aby súbežné požiadavky neminuli rovnaký zostatok. Úspešné dokončenie rezerváciu zaúčtuje; chyby ju uvoľnia. Prebiehajúce požiadavky dočasne znižujú zostatok; opustené rezervácie vypršia po piatich minútach. Požiadavka patrí do mesiaca UTC, v ktorom bola vytvorená rezervácia.

Keď sa ďalšia požiadavka nezmestí do limitu

API vráti HTTP 429, error=credit_limit_exceeded a hlavičku Retry-After s časom mesačnej obnovy. Neopakujte požiadavku, kým sa limit neobnoví alebo tím neschváli zmenu balíka. Lacnejšia požiadavka môže prejsť, ak sa do zostatku zmestí. Nevzniká príplatok ani automatické zvýšenie balíka.

{
  "error": "credit_limit_exceeded",
  "message": "This request would exceed your chosen package’s monthly credit limit.",
  "plan": "free",
  "credit_limit": 1000,
  "used_credits": 998,
  "reserved_credits": 0,
  "requested_credits": 3,
  "remaining_credits": 2,
  "resets_at": "2026-12-01T00:00:00Z"
}

Overenie za 3 kredity je tu zablokované, ale dve požiadavky našepkávača po 1 kredite sa ešte zmestia. Zamietnutá požiadavka kredity nečerpá.

Našepkávanie sa počíta za požiadavku, nie za adresu

Štyri hľadania pri zadávaní ulice a čísla domu stoja 4 kredity. Zobrazenie a výber existujúceho návrhu samy ďalšiu požiadavku neposielajú. Jedno overenie pridá 3 kredity: 7 kreditov spolu. Vyhľadanie firmy zvýši súčet na 12. Použite oneskorenie pri písaní a zabráňte duplicitným dopytom; jedno stlačenie klávesu nemusí znamenať jednu požiadavku. Ukážka na úvodnej stránke vybranú úplnú adresu automaticky overí; samostatný overovací formulár pošle požiadavku až po odoslaní.

Balíky a kalkulačka spotreby

Presný kreditový zostatok

GET /account/api/credits?month=YYYY-MM s vaším Bearer API kľúčom vracia zvolený balík, limit, spotrebované kredity, rezervácie, zostatok, súčty podľa operácií, dátum obnovy a začiatok merania. Bez mesiaca sa použije aktuálny mesiac UTC. Prehľad zostatku, stav služby ani dokumentácia kredity nečerpajú. Historické spoločné počty dopytov sa spätne neprenášajú na kreditové poplatky.

Použite stránku účtu na zobrazenie spotreby a žiadosť o balík. Platené balíky musí tím schváliť a aktivovať; platba sa automaticky nevyberá. Zmena balíka neobnoví už spotrebované kredity. Verejné ukážky majú samostatný kľúč a nečerpajú zákaznícke limity. Zdieľajú denný limit 10 000 kreditov za pokusy v UTC; chyba HTTP 429 demo_limit_exceeded vyzve návštevníka na žiadosť o vlastný kľúč.

Spracujte chyby výslovne.

Pred použitím odpovede skontrolujte HTTP stav. Chyby API nečerpajú kredity.

StavČo urobiť
400Skontrolujte krajinu, IČO, príznaky dopytu a polia adresy. Chyby parametrov Companywise môžu byť obyčajný text; nepredpokladajte, že každá chybová odpoveď je JSON.
401Pošlite aktívny kľúč správnym spôsobom.
403Pri našepkávaní skontrolujte zhodu Origin alebo Referer s povolenou doménou.
429Pri chybe credit_limit_exceededneopakujte požiadavku do obnovy limitu alebo schválenej zmeny balíka. Vyčerpanie verejnej ukážky používa demo_limit_exceeded.
5xxDočasná chyba služby alebo zdroja. Opakujte s oneskorením a rozumným limitom pokusov.

Úspešná HTTP odpoveď môže byť bez zhôd alebo obsahovať adresu na kontrolu. Spracujte ich ako výsledok aplikácie, nie chybu prenosu.

Spoločný prehľad spotreby

GET /account/api/usage prijíma Authorization: Bearer YOUR_API_KEY a vracia dennú spotrebu tohto kľúča pre aktuálny mesiac; pridajte month=YYYY-MM pre starší mesiac, rozdelený podľa produktov. Cudzie zákaznícke údaje a kľúče sa nevracajú.

curl 'https://addresswise.eu/account/api/usage' \
  -H 'Authorization: Bearer YOUR_API_KEY'

Každý riadok obsahuje api_key_id, label, product, date a requests. Existujúce pravidlá a historické počítadlá Addresswise sa zachovávajú. Spotreba sa ukladá každých niekoľko sekúnd.
