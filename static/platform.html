    Before you integrate

    The details, without the guesswork.

    Does every keystroke cost a credit?

    No. Each successful autocomplete request costs 1 credit. Your integration decides when to send a request. Debounce typing to avoid sending a request on every keystroke. Selecting an existing suggestion sends no request by itself. The live homepage demo automatically validates a selected complete address, which would add 3 credits on a customer key.

    What happens when I reach my limit?

    Any request that would exceed your remaining balance returns HTTP 429 with credit_limit_exceeded. It uses no credits. There is no automatic upgrade or overage fee. You can request a larger package, or wait for the monthly reset.

    Do empty results and repeated lookups count?

    Yes. A successful response counts even if no company or address is found, or validation returns valid=false. Repeated and cached successful requests count again. Invalid-input, authentication, server and quota errors cost zero. A request completed by the server can count even if the browser later aborts it.

    How do I get a key and start paying?

    Register and choose your plan on the API access page. Your Free key works immediately. Paid upgrades require confirmed payment. Existing Addresswise keys also work for Companywise. Prices are per monthly package, not per product.

    What data and countries do you support?

    Addresswise supports the European countries available in the demo selector. Companywise supports Czech and Slovak company IDs. Company data includes names, addresses, formation dates, NACE IDs and VAT status where sources provide them. Check source freshness and unknown values before making business decisions.
