5. Credit consumption and hard limits

Each successful autocomplete response costs 1 credit; a completed address validation costs 3 credits; a company-details response, including the VAT check, costs 5 credits. Companywise minimal/full modes and register selection have the same cost. Each successful request is counted separately, including repeated or cached requests and empty results. Validation returning valid=false is a completed result and counts. Invalid-input, authentication, upstream/server and quota errors consume no credits. A request completed on the server may count even if the client disconnects.

The customer chooses a hard package limit. A request that would exceed the remaining balance is blocked with HTTP 429 and credit_limit_exceeded and is not charged. There are no automatic package upgrades or overage charges. A lower-cost request can still succeed if it fits. Credits may be temporarily reserved for in-progress requests.
