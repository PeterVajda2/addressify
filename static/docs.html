Autocomplete in a browser: the browser supplies your Origin automatically. Register your website domain with your key. Its subdomains are included automatically. Companywise also accepts api_key in the query string. Prefer the Bearer header for server requests. The public site’s demo key is for the public demos; request your own key for an integration.

Addresswise · 1 credit per response

Autocomplete an address, street first.

Address entry always starts with the street. Use this sequence for a checkout or CRM form:

  1. Suggest streets. Send the text and country with the bare street_only flag.
  2. Add the house number. Once a street is selected, search again without street_only for complete addresses.
  3. Fill your form. Use the selected result’s address object to fill city and postal code. Validation is a separate, optional request.
GET/search
Request · Autocomplete
curl 'https://addresswise.eu/search?q=Hlavna&country=SK&limit=5&api_key=YOUR_API_KEY&street_only' \
  -H 'Origin: https://YOUR_ALLOWED_DOMAIN'

1 credit per successful response · allowlist your website domain

Example JSON response (abbreviated)
{
  "results": [
    {
      "formatted": "Hlavná, Košice, SK",
      "address": {
        "thoroughfare": "Hlavná",
        "locality": "Košice",
        "country_code": "SK"
      }
    }
  ]
}
Important: use &street_only, not &street_only=true. Remove the flag when searching for a house number. Debounce typing (the homepage demo uses 300 ms); each completed request costs 1 credit.
Query parameterUse
qStreet text, then street and house number.
countryTwo-letter code, for example CZ or SK. See the live tool for currently available countries.
limitMaximum number of suggestions, for example 5.
api_keyYour active API key with an allowed domain.
street_onlyBare flag for street suggestions; omit for complete addresses.

Use the structured result

Read results[]. Each result has formatted, score, country_code and address. The address object includes thoroughfare (street), premise (house number), locality (city), postal_code and full_address, plus optional administrative and sub-address fields. Optional values can be null.

Existing API integrations

/suggest remains an alias for search. Existing postal_only and postal_code parameters remain supported for compatibility. The website uses the street-first flow only.

Addresswise · 3 credits per response

Validate a complete address.

Send a structured address after selection, or validate one you already have. This request is independent of autocomplete.

POST/validate?api_key=YOUR_API_KEY
Request · Address validation
curl 'https://addresswise.eu/validate?api_key=YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"street":"Hlavná","house_number":"1","postal_code":"04001","city":"Košice","country":"SK"}'

3 credits per successful response · an address needing review also counts

Example JSON response (abbreviated)
{
  "valid": true,
  "confidence_ratio": 1.0,
  "corrected_address": {
    "thoroughfare": "Hlavná",
    "premise": "1",
    "locality": "Košice",
    "postal_code": "04001",
    "country_code": "SK"
  }
}

The JSON body uses country, street, house_number, postal_code and city. No Origin header is required. Responses contain valid, confidence_ratio, corrected_address and suggestions.

Handle “needs review”. HTTP 200 with valid=false is a completed validation, not an API error. Show the suggestions or let the user review their entry. It costs 3 credits.

Use CZ or SK and an eight-digit company ID as text, preserving leading zeros. The VAT check is included in the same request.

Request · Company details
curl 'https://addresswise.eu/companywise/api/v1/subjects/CZ/27082440?minimal=true' \
  -H 'Authorization: Bearer YOUR_API_KEY'

5 credits per successful response · VAT included

Example JSON response (abbreviated)
{
  "country": "CZ",
  "ico": "27082440",
  "records": [
    {
      "name": "Alza.cz a.s.",
      "established_on": "2003-08-26",
      "addresses": [
        {
          "city": "Praha"
        }
      ]
    }
  ]
}
ModeWhat you receive
minimal=trueCompact records[] with name, established_on, nace_codes and structured addresses, plus VAT summary.
minimal=false (default)Detailed registry.records[], register metadata, original source data and VAT evidence.
all_registers=trueInclude all available registers rather than the default commercial/trade selection. Works with either response mode.

Useful normalized fields

established_on
Company formation date as YYYY-MM-DD, or null when unavailable.
nace_codes
Category IDs as strings, without labels. CZ uses current ARES CZ-NACE codes; SK supplies the main activity ID where available.
addresses[].city and municipality
CZ city uses the separate source town name. SK city is derived by shortening explicit Bratislava/Košice borough prefixes. Original municipality is preserved.
vat and freshness
Check unknown values and stale flags. Unknown VAT status does not mean the company is not a VAT payer.

Minimal and full responses both cost 5 credits. A completed empty company lookup also counts. Detailed sources, nullable fields, errors and populated examples are documented in the full schema.

Credits & chosen-package limits

One monthly credit allowance is shared by both products on the same API key. Autocomplete (/search or /suggest) costs 1 credit per successful request; POST /validate costs 3; a Companywise lookup costs 5, with the same cost for minimal/full and register options.

A successful HTTP response counts even when autocomplete returns no matches, validation returns valid=false, or company retrieval has no selected register record. Repeated and cached successful lookups count again. Invalid input, authentication failures, upstream/server failures and quota rejections cost zero. If a browser aborts a request after the server has completed it, the completed request may still count.

The fixed monthly packages are Free (€0, up to 1,000 credits), Starter (€9, up to 100,000), Growth (€19, up to 1,000,000), and Custom (an agreed hard limit and quote). These are chosen packages, not automatic usage-based upgrades. Allowances are totals, not extra credits on top of Free; unused credits do not roll over. The allowance resets at 00:00 UTC on the first day of each calendar month.

Credits are reserved atomically before work begins so concurrent requests cannot spend the same remaining balance. Successful completion charges the reservation; errors release it. Pending requests can temporarily reduce the available balance; abandoned reservations expire after five minutes. A request belongs to the UTC month in which its reservation was created.

When the next request does not fit

The API responds with HTTP 429, error=credit_limit_exceeded and a Retry-After header pointing to the monthly reset. Stop retries until the allowance resets or the team approves a package change. A lower-cost request can still succeed if it fits the remaining balance. There is no automatic overage fee or package upgrade.

{
  "error": "credit_limit_exceeded",
  "message": "This request would exceed your chosen package’s monthly credit limit.",
  "plan": "free",
  "credit_limit": 1000,
  "used_credits": 998,
  "reserved_credits": 0,
  "requested_credits": 3,
  "remaining_credits": 2,
  "resets_at": "2026-12-01T00:00:00Z"
}

Here a validation (3 credits) is blocked, but two autocomplete requests (1 each) would still fit. A rejected request consumes no credits.

Autocomplete is per request, not per completed address

Four searches while typing a street and house number use 4 credits. Showing or selecting an existing suggestion adds no request by itself. One validation then adds 3: 7 credits total. Adding one company lookup makes 12. Debounce browser input and avoid duplicate requests; do not assume one keystroke always equals one request. The public homepage demo validates selected complete addresses automatically; the full tool’s validation form sends a request only when submitted.

Package cards & consumption calculator

Authoritative credit balance

GET /account/api/credits?month=YYYY-MM with your Bearer API key returns the chosen package, credit limit, successful credits used, pending reservations, available balance, per-operation totals, reset date and metering start time. Omitting month selects the current UTC month. Reading balances, health checks and documentation does not consume credits. Historical combined address counters are not converted into credit charges.

Use the account page to see usage and request a package. Paid/custom packages require team approval and activation; no online payment is collected automatically. A package change does not reset credits used this month. Public website demos use a separate demo key and do not spend customer allowances. They share a fair-use allowance of 10,000 attempted credits per UTC day; HTTP 429 demo_limit_exceeded asks visitors to request their own key once this is reached.

Handle errors explicitly.

Check the HTTP status before using the response. API errors do not spend credits.

StatusWhat to do
400Check country, IČO, query flags or address fields. Companywise query validation can return a plain-text error, so do not assume every error body is JSON.
401Supply an active key using the correct authentication style.
403For autocomplete, check that Origin or Referer matches an allowed domain.
429For credit_limit_exceeded, stop retries until the reset or an approved package change. Public demo exhaustion uses demo_limit_exceeded.
5xxTemporary service or upstream error. Retry with backoff and a sensible limit.

A successful HTTP response may still contain no matches or an address needing review. Handle those as application results, not transport errors.

Shared usage

GET /account/api/usage accepts Authorization: Bearer YOUR_API_KEY and returns this key’s daily usage for the current calendar month; add month=YYYY-MM to retrieve an earlier month, separated by product. No customer data or other keys are returned.

curl 'https://addresswise.eu/account/api/usage' \
  -H 'Authorization: Bearer YOUR_API_KEY'

Each row includes api_key_id, label, product, date and requests. Addresswise’s existing counting rules and historical counters remain intact. Its usage is flushed every few seconds.
